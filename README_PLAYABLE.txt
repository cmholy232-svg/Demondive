DEMONDIVE — FULL CAMPAIGN ALPHA 7.3C

FASTEST WINDOWS START
1. Extract the entire ZIP. Do not run it from inside the ZIP viewer.
2. Double-click START_DEMONDIVE.cmd.
3. Keep the server window open while playing.
4. The game opens at http://127.0.0.1:4173/.

This package does not require npm install or esbuild approval. It only needs
Node.js 18 or newer. If Windows blocks the CMD file, right-click
START_DEMONDIVE.ps1, choose Run with PowerShell, or run `node serve.mjs` in
this folder and open the address printed in the terminal.

The campaign now runs from Level 1 through Level 9 and the mechanical ending.
Level 8 contains Lilith's Daughters and Lilith, the Succubus Queen. Level 9
contains the seven-Lord boss rush, The Hollow, Milo's acceptance ending, and
functional credits. Every mini-boss is at the midpoint and every boss is last.

For focused testing, use the Hellroom upgrade desk, open Playtest Tools, and
choose a direct jump through Level 9.
