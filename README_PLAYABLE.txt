DEMONDIVE — ALPHA 7.7 STORY & TUTORIAL PLAYTEST

FASTEST WINDOWS START
1. Extract the entire ZIP. Do not run it from inside the ZIP viewer.
2. Double-click START_DEMONDIVE.cmd.
3. Keep the server window open while playing.
4. The game opens at http://127.0.0.1:4173/.

This package does not require npm install or esbuild approval. It only needs
Node.js 18 or newer. If Windows blocks the CMD file, right-click
START_DEMONDIVE.ps1, choose Run with PowerShell, or run `node serve.mjs` in
this folder and open the address printed in the terminal.

The campaign runs from Level 1 through Level 9 and the acceptance ending.
Level 8 contains Lilith's Daughters and Lilith, the Succubus Queen. Level 9
contains the seven-Lord boss rush, The Hollow, Milo's acceptance ending, and
functional credits. Every mini-boss is at the midpoint and every boss is last.

Fresh saves now enter a playable three-room tutorial. Levels 4–9 contain a
playable dialogue draft at each entrance, mini-boss, boss and aftermath. These
lines are not final narrative approval and remain skippable.

For focused testing, use the Hellroom upgrade desk, open Playtest Tools, and
choose a direct jump through Level 9.

The current build uses smart two-choice boon offers, progressive campaign lengths,
stronger story/challenge pressure, and unbounded Deep Dive scaling. Death
retries restart Level 1, Settings can create a truly fresh save, Nerissa's
chant pillars enforce her invulnerability, and repaired fixed-cell sprites
remove the reported Neon Maw, Belladonna, and Milo cast clipping.

Alpha 7.4 engineering, Alpha 7.5 art integration, and Alpha 7.6 code-side
feedback/audio systems are included. Final authored SFX, unresolved art-source
corrections, and hands-on keyboard/controller/device approval remain open.

Use ALPHA7_3C_PLAYTEST_CHECKLIST.md as the full-campaign test record and
CURRENT_BUILD_STATUS.md for the exact gate. Automated verification is not a
substitute for subjective combat, difficulty, audio, visual or narrative approval.
